Advanced Excel Export with Templates

Export any Odoo list to a professionally formatted Excel file in two clicks. Define reusable templates per model — choose which fields to include, set custom headers, column widths and colours, enable totals rows and alternating row shading. Comes with ready-made templates for Sale Orders, Customer Invoices and Purchase Orders.

🎨 Formatted output

Custom header colour, font colour, alternating row shading, frozen header row and auto-fit or fixed column widths.

Σ Totals row

Mark any numeric column as "Sum in footer" and a totals row is automatically added at the bottom.

🔗 Dotted field paths

Export related fields using dotted paths like partner_id.name or user_id.email — no custom code needed.

📋 Reusable templates

Create once, reuse forever. Templates are model-specific and auto-selected when you open the export wizard.

Included templates (ready to use)

  • Sale Orders: Order, Date, Customer, Salesperson, Untaxed, Tax, Total, Status — with totals row.
  • Customer Invoices: Invoice, Dates, Customer, Untaxed, Total, Amount Due, Payment Status — with totals.
  • Purchase Orders: PO Number, Date, Vendor, Total, Status — with totals row.

How to use

  1. Go to any list view (Sale Orders, Invoices, etc.) and select the records you want to export.
  2. Click Action → Export to Excel.
  3. The matching template is pre-selected. Click Generate Excel.
  4. Download the formatted .xlsx file.

Create your own template

  1. Go to Settings → Excel Export Templates.
  2. Create a new template, select the model, set colours and header options.
  3. Add columns: enter the field name (or dotted path), set a custom header, format and width.
  4. Save — the template is immediately available in the export wizard for that model.
