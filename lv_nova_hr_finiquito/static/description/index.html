Employee Termination & Finiquito (LATAM)

Calculate all termination payment components automatically from the employee's contract, salary and years of service. Generate a professional "Acta de Finiquito" PDF ready for signatures — no more error-prone spreadsheets. Designed for Ecuador with flexibility for Colombia, Peru and similar regimes.

🧮 Auto-calculation

One click computes all components: proportional vacation, 13th/14th month, reserve funds, severance and indemnification.

📋 Termination types

Desahucio, Visto Bueno, Voluntary Resignation, Mutual Agreement, End of Contract — each activates the correct components.

📄 Printable Acta de Finiquito

Professional PDF with both parties' data, the full component breakdown, legal declaration text and signature lines.

✅ Approval workflow

Draft → Confirmed → Paid. HR Officers compute; Managers confirm. Full chatter audit trail.

How to use

  1. Go to Employees → Finiquitos → New.
  2. Select the employee — the contract, start date and salary fill automatically.
  3. Set the termination date and type.
  4. Toggle which components to include and click Compute Finiquito.
  5. Review and add deductions if needed. Confirm and print.
