Product Labels with QR Code — Bulk Print

Print professional product labels in bulk directly from Odoo — no external label software needed. Select products, choose a label size and the fields to show, and generate a ready-to-print PDF with QR codes, barcodes, prices and lot numbers laid out in a crisp grid.

📦 Three label sizes

70×36 mm (standard), 48×30 mm (small shelf labels), 100×50 mm (large product labels). All print on A4.

📱 QR code

Each label includes a QR code encoding the barcode, reference, product name, or both. Scans with any smartphone.

🔢 Quantity per product

Print 1 label or 500 for the same product. When printing from a Purchase Order, quantities pre-fill automatically.

🔗 Three entry points

Print from the Products list (multi-select), from a Purchase Order form, or from a Delivery / Receipt form.

Configurable fields per label

  • Product Name
  • Internal Reference
  • Sale Price (or custom price)
  • Product Category
  • Lot / Serial Number
  • Barcode (text)
  • QR Code image

How to print

  1. From Products: go to Inventory → Products, select products, Action → Print Labels.
  2. From Purchase Order: open any confirmed PO, click 🏷 Print Labels. Lines pre-fill with PO quantities.
  3. From Delivery/Receipt: open any stock picking, click 🏷 Print Labels.
  4. Configure size, fields and QR content in the wizard → click Print Labels.

Compatibility

Odoo 18.0 Community Enterprise Requires: Inventory, Purchase Python: qrcode

Technical notes

  • Requires the qrcode Python library (included in Odoo's default dependencies). If not present, labels print without QR codes.
  • PDF is generated by wkhtmltopdf, standard Odoo PDF engine — no extra setup needed.
  • Custom price per line overrides the product's list price on the label only — it does not modify the product's actual price.
