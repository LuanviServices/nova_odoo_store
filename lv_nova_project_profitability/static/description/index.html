Project Profitability Report

Know exactly how much each project earned and cost. This module combines invoiced revenue, timesheet labor costs, and vendor bill purchases — all linked via analytic accounts — into a single profitability view per project, with a color-coded list and a printable PDF breakdown.

📊 Profitability dashboard

Color-coded list of all projects: green (≥15% margin), amber (0–15%), red (negative). Sortable by any column.

💰 Three cost sources

Timesheet labor (hours × employee rate), vendor bills, and purchases — all linked via analytic accounts.

📄 PDF report

Print a detailed breakdown per project: revenue lines, timesheet entries, and purchase lines with full drill-down.

🔢 Margin % smart button

The project form shows the current margin % in a smart button — click to open the full profitability view.

How it works

  1. Each project needs an Analytic Account configured (set it in the project settings tab).
  2. Open Project → Profitability to see all projects side by side.
  3. Click any project to see the KPI strip (invoiced, costs, margin, margin %).
  4. Click Print PDF to export a detailed report with every invoice, timesheet entry, and vendor bill.

Data sources used

  • Revenue: posted customer invoice lines whose analytic distribution includes the project's analytic account.
  • Timesheet cost: account.analytic.line records linked to the project × employee timesheet_cost rate.
  • Purchase cost: posted vendor bill lines whose analytic distribution includes the project's analytic account.
  • Partial analytic allocations (e.g. 60% to this project) are respected — only the allocated % is counted.

Compatibility

Odoo 18.0 Community Enterprise Requires: Project, Accounting, Timesheets
