Recurring Tasks Manager

Stop relying on sticky notes, calendar reminders or spreadsheets for regular operational tasks. Define recurring task templates, let Odoo generate the instances automatically, and track completion from a Kanban board. Know at a glance what's overdue, due today and coming up — and measure reliability with completion rate stats.

📅 Six frequencies

Daily, weekly, bi-weekly, monthly, quarterly and yearly templates. Each auto-generates the next task at the right time.

🗂 Kanban board

Tasks grouped by state: Pending, Done, Overdue, Skipped. Color-coded cards make it easy to spot what needs attention.

📊 Completion stats

Each template tracks how many instances were completed on time. Completion rate shown on the template list and in the PDF report.

🔔 Auto-overdue

Daily cron marks tasks as overdue automatically if they pass their due date without being completed or skipped.

Frequency options

Yearly14 days aheadAnnual reviews, renewals

How to use

  1. Go to Recurring Tasks → Templates → New.
  2. Enter the task name, instructions, frequency and assignee.
  3. Odoo generates instances automatically each day via cron. You can also click Generate Next Instance manually.
  4. Open Task Board to see all pending/overdue tasks in a Kanban view.
  5. Click Mark as Done or Skip on each task.
