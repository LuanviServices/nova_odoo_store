Inter-Warehouse Transfer Approval

Prevent stock from moving between warehouses without authorisation. Enable approval on a per-warehouse basis — any internal transfer arriving at that warehouse must be approved before it can be validated. The responsible manager is notified via Odoo chatter, can approve or reject (with a mandatory reason), and the transfer is blocked until the decision is made.

🏭 Per-warehouse toggle

Enable approval on the destination warehouse. You can also assign a specific approver; if empty, any Stock Manager can approve.

🔔 Chatter notifications

The approver is notified when a transfer is submitted. The requester is notified when it's approved or rejected.

✘ Rejection with reason

Rejecting a transfer opens a wizard requiring a mandatory explanation. The reason is visible on the transfer and in the chatter.

🔒 Blocked validation

Odoo shows a clear error if someone tries to validate a transfer that is still pending or was rejected.

How to set up

  1. Go to Inventory → Configuration → Warehouses.
  2. Open the destination warehouse → Transfer Approval tab.
  3. Enable "Require approval for incoming internal transfers".
  4. Optionally assign a specific approver. Leave empty for any Stock Manager.

Compatibility

Odoo 18.0 Community Enterprise Requires: Inventory

Technical notes

  • Only applies to picking_type_code == 'internal' transfers.
  • The check is based on the destination location's warehouse, not the source.
  • No new database tables — only new fields on stock.picking and stock.warehouse.
  • The approval state is tracked and visible in the chatter history.
